# Problem Statement

Traditional ticket booking can be time-consuming when users have to manually check seat availability, booking details, and cancellation status. There is also a possibility of duplicate booking when multiple users try to reserve the same seat at the same time. This project aims to develop a Java-based Online Ticket Booking and Reservation System that provides a simple and efficient way to register users, view shows and seats, book and cancel tickets, maintain booking records, and handle simultaneous booking attempts using multithreading and synchronization.

# Scope of the Project

The project covers the basic operations required for an online ticket booking system. Users can register and login, view available shows and seats, book tickets, make payments, find booking details, cancel bookings, and view booking records. Booking information is stored using file handling. The project also demonstrates concurrent booking management using Java multithreading and synchronization. The system is designed as a command-line application for academic and demonstration purposes.

# Target Users

- Customers who want to book and cancel tickets.
- Users who want to check available shows and seats.
- System administrators or operators who need to view booking records.
- Students and learners who want to understand Java concepts through a practical project.

# High-Level Features

- User registration and login
- Show and seat availability management
- Online ticket booking
- Payment processing
- Automatic booking ID generation
- Duplicate seat booking prevention
- Booking search and cancellation
- Booking history and record management
- File-based storage of booking details
- Multithreading for simultaneous booking requests
- Synchronization to prevent race conditions
- Exception handling for invalid operations
